How MFA Relay Works

  1. Victim submits username + password on the proxied login page (stage 1).
  2. DropoutJeep stores credentials in MfaRelayState with a TTL ({{ ttl }}s).
  3. Victim sees the real MFA prompt (TOTP, push, SMS) and submits their code.
  4. DropoutJeep replays credentials + MFA code to the real target.
  5. If successful, session cookies are captured and the victim sees the real success page.
