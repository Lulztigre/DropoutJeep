Configure the SAML/SSO relay flow. When a victim submits a SAMLResponse to the /saml/acs/<token> endpoint, it is captured for analysis. Optionally, it can be forwarded to the real service provider ACS to establish a session.

If set, captured SAMLResponses will be automatically relayed to this URL so the victim's session is established. Leave blank to capture-only mode (no relay).

How SAML Relay Works

  1. Victim is redirected to the real IdP login page via your phishing email link.
  2. After authentication, the IdP POSTs a SAMLResponse to your /saml/acs/<token> endpoint.
  3. DropoutJeep captures the SAMLResponse, RelayState, and metadata.
  4. If Real ACS URL is set, the SAMLResponse is forwarded to the real SP so the victim gets a valid session.
  5. You can review captured SAML responses in the VIEW CAPTURES page.
